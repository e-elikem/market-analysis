## Market Data Analysis

The goal for this project was to perform a market analysis by do the following:

* Inspect and clean the data for analysis
* Develop questions for analysis
* Analyze variables within the data to gain patterns and insights that answer questions
* Visualize data and results of analysis


### Data 

The data for this project was downloaded from Kaggle:

[https://www.kaggle.com/jackdaoud/marketing-data](https://www.kaggle.com/jackdaoud/marketing-data)
